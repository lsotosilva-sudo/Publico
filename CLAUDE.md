## Rama

**Se trabaja directo sobre `main`**, salvo que Lucho pida otra cosa. Aunque el entorno de la sesión asigne
una rama `claude/...`, los cambios se commitean y se suben a `main` (`git push origin HEAD:main`), sin ramas
de feature ni pull requests. Decisión de Lucho, 24-11-2026.

Empujar a `main` **es publicar**: GitHub Pages sirve el repo en https://lsotosilva-sudo.github.io/Publico/
