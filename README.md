# Publico

Páginas y herramientas públicas. No contiene claves ni datos privados.

- `vanta/firma.html` — crea una clave de trading de Vanta (Orderly, `read,trading`, no puede retirar)
  firmando desde la wallet. Abrir desde el navegador interno de la wallet:
  https://lsotosilva-sudo.github.io/Publico/vanta/firma.html
- `lighter/firma.html` — firma con la wallet (personal_sign) el mensaje de registro de una clave de API de Lighter.
  El mensaje llega en el link (#m=...), nunca se envía a un servidor.
